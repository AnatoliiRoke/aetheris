## 2. Клан (💡)

| Параметр | 💡 Пропозиція |
|---|---|
| Створення | Гравець від певного рейтингу + кредити |
| Розмір | ✅ Ліміт учасників росте з рівнем клану (💡 наприклад, 20 → 100) |
| Ролі | Глава, офіцери, ветерани, учасники, новобранці |
| Права | Хто приймає, виключає, оголошує війну, витрачає склад |
| Клановий склад | ✅ Спільне сховище ресурсів і деталей; внески учасників |
| Клановий ринок | ✅ Є |
| Рівень клану | ✅ Є; 💡 росте від спільних досягнень (бої, видобуток, вторгнення) |
| Чат і пошта | Так |

## 4. Дипломатія (✅ усі види стосунків є на старті)

| Стосунки | Що дає |
|---|---|
| **Війна** | ✅ Послаблені обмеження на атаки між кланами. ✅ Автоматично закінчується, якщо 7 днів немає боїв |
| **Мирний договір** | Атаки заборонені на певний строк |
| **Союз / взаємодопомога** | Можна приєднуватися до боїв союзника, спільний захист |
| **Торговельна угода** | Знижена комісія між кланами, доступ до ринку один одного |
| **Ембарго** | Заборона торгівлі між кланами |
| **Обмін розвідкою** | Спільний огляд радарами (документ 09) |
| **Відкриті кордони** | Польоти в системи один одного без обмежень |

- 💡 Стосунки мають мінімальний строк (наприклад, 3–7 днів), щоб їх не змінювали щогодини.
- ✅ Усі сім видів стосунків доступні з запуску гри.

## 5. Гільдії ✅ (ідея з референсу; 💡 деталі)

✅ Гільдії — це **особиста спеціалізація гравця** (незалежно від клану) з невеликими бонусами. 💡 Перелік:

| Гільдія | 💡 Бонус |
|---|---|
| Торговців | +лоти на ринку, −комісія, швидші конвої |
| Шахтарів | +видобуток, краща геологорозвідка |
| Найманців | +урон і швидкість у бою |
| Промисловців | +швидкість виробництва деталей |

- Гравець може бути лише в одній гільдії; вступ — за кредити або (❓) за преміум-валюту.
- ✅ Гільдії «Незалежних світів» (захист в обмін на відмову від атак) **немає**.
