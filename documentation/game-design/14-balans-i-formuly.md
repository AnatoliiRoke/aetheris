## 1. Принципи балансу (💡)

✅ **Жодного хардкоду** (автор, 25.10.2026): усі числа, множники й коефіцієнти цього документа є **параметрами конфігурації в базі даних, а не константами в коді**; сервер тримає їх у пам'яті (tech/03, розділ 1). У коді лише структура формул. Значення тут стартові й змінюються під час прогонів.

1. **Усі числа — параметри.** Кожне число з цього документа в коді має бути налаштуванням (конфіг), а не вписаним значенням. Це важливо для розробника-одинака: баланс змінюється без нового релізу.
2. **Геометричне зростання.** Вартість і час рівнів ростуть множником, видобуток — повільніше. Так кожен новий рівень дорожчий за попередній.
3. **Невеликі бонуси.** Раса, командир, модуль Mk, артефакт дають по кілька відсотків; разом вони **множаться**, тому кожне джерело має бути малим.
4. **Ліміт сукупного бонусу** 💡: сума всіх бонусів до одного параметра не більше +50%.
5. **Казуальний ритм:** сховище заповнюється за 8–12 год, населення відновлюється лінійно приблизно за 20 годин (5% максимуму на годину).

## 2. Економіка

### 2.1. Видобуток на планеті
```
видобуток/год = база_ресурсу × рівень × 1.1^рівень × (1 + бонус_типу_планети + бонус_технологій)
```
| Параметр | 💡 Значення |
|---|---|
| база (метали) | 450/год (стартове значення, підтягуємо симулятором; було 30) |
| база (кристали) | 225/год (було 15) |
| база (паливо на газовому гіганті) | 300/год (було 20) |
| бонус типу планети | ±10–30% (документ 03) |
| технології видобутку | +2% за рівень |

### 2.2. Вартість і час будівлі
```
вартість(рівень) = базова_вартість × 1.5^(рівень−1)
час(рівень)      = базовий_час × 1.4^(рівень−1)
```
| Параметр | 💡 Значення |
|---|---|
| базовий час (шахта) | 30 секунд |
| базовий час (верф, дослідницький центр) | 5 хвилин |
| максимальний рівень будівлі | ✅ 20 |

💡 Приклад: шахта 10 рівня будується ≈ 30 с × 1.4⁹ ≈ 10 хвилин; 20 рівня ≈ 30 с × 1.4¹⁹ ≈ 10 годин.

### 2.3. Енергія
```
енергія = Σ (база_станції × рівень × 1.1^рівень) − Σ споживання_будівель
якщо енергія < 0: швидкість усіх будівель × (вироблено / потрібно)
```

### 2.4. Сховища
```
місткість(рівень) = 5000 × 1.3^(рівень−1)   (було ×1.6; стартове значення, підтягуємо симулятором)
захищена_частина  = 20% + 3% × рівень_бункера   (максимум 50%)
```

### 2.5. Населення і кредити
```
приріст/год       = 5% × максимум_населення   (лінійно, зручно для лінивого обчислення)
кредити/год       = поточне_населення / 10
максимум          = база_планети × (1 + бонус_типу) + житлові_комплекси × 500
```
✅ Населення відновлюється до максимуму; екіпаж розібраного корабля повертається (не вище максимуму).

### 2.6. Утримання флоту
```
утримання/год = Σ (утримання_корпусу + Σ утримання_модулів)
паливо_на_переліт = витрата_двигуна × відстань × (1 + 0.1 × кількість_важких_кораблів_у_флоті)
```
✅ Без кредитів флот не літає, але обороняє планету.

### 2.7. Ринок
| Параметр | 💡 Значення |
|---|---|
| комісія: клановий / секторний / всегалактичний | 1% / 5% / 10% |
| ціна лота | у межах 50–200% від середньої за 7 днів; ✅ виняток: ціна 0 (передача ресурсів) |
| портал: енергострижні | 1 стрижень на 1000 одиниць × (1 + відстань у секторах) |

### 4.3. Обмеження конструктора
```
Σ енергія_модулів ≤ Σ потужність_генераторів       (✅)
Σ слотів за розміром ≤ слоти корпусу                (💡)
швидкість = база_двигуна × (маса_корпусу / маса_повна)  (❓ якщо вводимо масу)
екіпаж = екіпаж_корпусу + Σ екіпаж_модулів × (1 − бонус_бортового_комп'ютера)
```

## 5. Бій

### 5.1. Постріл
```
шанс_влучити = точність_зброї × (1 + бонус_радара) × (1 − РЕБ_цілі) × множник_розміру_цілі
урон         = урон_зброї × множник_класу[стрілок][ціль] × множник_типу[тип_урону][захист]
```
Порядок поглинання: **щит → броня → корпус**. ✅ Щити частково відновлюються між циклами (💡 30%), броня й корпус — ні.

### 5.3. Множники типів урону (💡, документ 05a, розділ 7)

### 5.3а. Модель щита (✅ механіка від автора, 25.10.2026; числа 💡 стартові)

- Щит захищає **одночасно від різних типів урону, але з різним коефіцієнтом поглинання**. Приклад: енергетичний урон 90%, фізичний 50%.
- Щит має **насичення** (запас). Частина залпу, яку щит поглинає (залп × коефіцієнт), **зменшує насичення**; решта проходить до броні.
- Насичення відновлюють спеціальні модулі (наприклад, «Відновлювач щитів», документ 05a).
- **Приклад:** залп 1000 енергетичного урону, коефіцієнт щита 90%, насичення 2000 → щит поглинає 900 (насичення 2000 → 1100), 100 проходить до броні.
- Спеціалізовані щити (документ 05a) = щити з високим коефіцієнтом для одного типу урону.
- ✅ Броню можуть відновлювати **ремонтні дрони з трюму** (обмежена кількість); дрони знищуються легкими кораблями або ймовірнісно, коли урон проходить крізь щит до броні, а при пробої трюму можуть загинути всі дрони, що лишилися в ньому (деталі: документ 05a). Ймовірності 💡 стартові.
- ✅ (автор: «норм») Коли насичення менше за те, що щит мав би поглинути: щит поглинає `min(залп × коефіцієнт, залишок насичення)`, решта до броні; при нульовому насиченні щит нічого не поглинає до відновлення.
- ❓ Чи коефіцієнти бувають різними для кожного рівня Mk (💡 так, вищий Mk = вищий коефіцієнт і більше насичення).
- Колонка «Спеціалізований щит» у таблиці 5.3 нижче (множник 0,5) застаріла: її замінюють коефіцієнти поглинання щитів. Множники для броні лишаються.

| Урон \ Захист | Броня | Енергетичний щит | Спеціалізований щит (свій тип) |
|---|---|---|---|
| Енергетичний | 0.8 | 1.2 | 0.5 |
| Плазмовий | 1.3 | 1.0 | 0.5 |
| Кінетичний | 1.0 | 0.8 | 0.5 |
| Іонний | 0.5 (але знімає енергію) | 1.0 | 0.5 |
| Вибуховий | 1.2 | 0.8 | 0.5 |
