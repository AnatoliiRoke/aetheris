# AETHERIS — екран керування цивілізацією (статична версія)

Без збірки й залежностей. Відкрий `index.html` у браузері або віддай папку будь-яким статичним хостингом.

```
index.html          розмітка-оболонка
css/styles.css      токени (:root), база, компоненти, mobile ≤ 767px
src/i18n.js         тексти UA / EN
src/icons.js        SVG-контури ресурсів, меню, будівель, подій
src/data.js         демо-дані планет і черг (замінити на API)
src/app.js          рендер, стан, таймери, події
assets/img/         WebP: 6 арт планет (ART-12a…f), туманність (ART-14), логотип (ART-16)
```

- `?lang=en` — англійські підписи; `?premium=0` — стандартний акаунт (2 місця в чергах). У демо чип «Преміум/Стандарт» у верхній панелі клікабельний.
- Таймери оновлюються щосекунди без перемальовування, тому скрол черг і поле чату не збиваються.
- Шрифт Inter підтягується з Google Fonts; без мережі працює fallback (Roboto, system-ui).
- Дані: `AE.PLANETS` у `src/data.js`. Для бойової версії замініть на відповідь API з тими ж полями.
