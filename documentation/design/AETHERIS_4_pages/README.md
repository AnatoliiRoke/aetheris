# AETHERIS — 4 сторінки (Планета, Будівництво, Дослідження, Склад)

- `html/` — по 2 файли на сторінку: десктоп (1440) і `-mobile` (390): planet, build, research, storage.
- `css/` — стилі кожної сторінки (одноіменний файл).
- `js/nav.js` — перехід між сторінками з бічного меню.
- `assets/` — зображення (фон, логотип, мініатюри планет).

Це статичні знімки екранів: без інтерактиву (вкладки, фільтри, таймери не працюють).
Більшість розмітки використовує inline-стилі, тому css/ невеликий.
Шрифт Inter підтягується з Google Fonts (потрібен інтернет).
Відкривати: двічі клацнути html/planet.html (або запустити `python3 -m http.server`).
