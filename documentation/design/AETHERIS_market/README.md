# AETHERIS — екран «Ринок» (html / css / js / assets)

- `html/` — 6 вкладок × 2 розкладки: `kupyty`, `prodaty`, `moi-loty`, `dostavky`, `obmin`, `istoriia` (десктоп 1440) і `*-mobile` (390).
- `css/` — стилі кожної сторінки (одноіменний файл).
- `js/nav.js` — перехід між вкладками та пунктом «Ринок» у меню.
- `assets/` — зображення (фон, логотип, мініатюри планет).

Це статичні знімки екрана: перемикання вкладок працює, але таблиці, форми, діалог купівлі й графік неінтерактивні.
Шрифт Inter підтягується з Google Fonts (потрібен інтернет). Відкривати: `html/kupyty.html`.
