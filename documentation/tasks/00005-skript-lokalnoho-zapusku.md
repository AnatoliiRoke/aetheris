# Задача 00005 — Скрипт локального запуску (сервер + клієнт однією командою)

> **Статус:** не розпочата (створено 25.10.2026). Маленька задача, виконується після 00001.
> **Документи:** [00001](00001-zibraty-stek-i-zapustyty-server.md), [tech/02 Стек](../tech/02-tekhnolohichnyi-stek.md)

## 1. Мета
Під час розробки потрібні два процеси: сервер (C#) і сервер клієнта Vite. Автор хоче запускати їх **однією командою**. Docker не використовуємо до релізу v0.1 (✅ автор, 25.10.2026).

## 2. Що входить
- Скрипт `dev.sh` у корені (macOS/zsh): перевіряє наявність .NET SDK (шукає також у `~/.dotnet` і додає в PATH лише для процесу), Node, доступність PostgreSQL і наявність рядка підключення (без виведення пароля); запускає сервер і клієнт одночасно, префіксує логи (`[server]`, `[client]`), при Ctrl+C зупиняє обидва процеси.
- Зрозумілі повідомлення про помилки українською (немає .NET, база недоступна, порт зайнятий).
- Розділ у README «Швидкий старт: одна команда».

## 3. Критерії приймання
1. `./dev.sh` піднімає сервер і клієнт, у браузері відкривається http://localhost:5173 з працюючим API.
2. Ctrl+C зупиняє обидва процеси, порти вільні.
3. Скрипт не виводить паролі й не змінює глобальні налаштування терміналу.
4. Якщо чогось не вистачає, скрипт називає, чого саме, і як виправити.

## 4. Що не входить
Docker, production-режим (віддача зібраного клієнта сервером робиться перед релізом v0.1 разом з Docker), Windows/Linux.
