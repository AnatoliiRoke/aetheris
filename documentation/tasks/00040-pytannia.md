# Задача 00040 — Питання до автора

> Файл створено під час виконання задачі 00040 (формування флотів). Тут лише те, що агент не міг перевірити, і те, що зроблено за замовчуванням.

## 1. Що агент не перевірив

1. **Chrome.** Playwright для проєкту не підключений. Ручний шлях «верф зібрала корабель → створити флот → додати корабель → розпустити» не пройдено. Сторінку перевірено лише тестами (vitest) і збркою.
2. **Робочий сервер.** Міграція `Fleets` і ключ `fleet.formation.name_max_length` з'являться після перезапуску сервера; процес не зупинявся. Міграція перевірена лише тестовою базою `aetheris_test`.
3. **CI** не запускався.

Живе тестування через справжній HTTP API проведено 08.11.2026 (див. §7 задачі 00040): створення флоту, додавання, вилучення, передача, перейменування, розпуск, ліміт і всі помилкові шляхи. Перевірено тільки API — ручний шлях через інтерфейс у Chrome не пройдено.

## 2. Рішення за замовчуванням

1. **Команди, яких немає у списку задачі, але є в макеті:** передача корабля між флотами однієї планети (`fleet.transfer_ship`) і перейменування (`fleet.rename`). Вилучення останнього корабля пропонує розпуск.
2. **Стан «Без кредитів»** показується, коли баланс кредитів цивілізації нульовий. Кредитами вважається валюта, яку приносить населення й яка не допускає боргу, та сама, що в складанні кораблів.
3. **Фільтр стану «У польоті»** з макета не зроблено: польотів і такого стану в даних немає. Фільтри: усі, готові, без кредитів.
4. **Рейтинг:** формули флотської складової немає, тому рейтинг не змінено. Модуль флотів віддає лише читання (`GetFleetFactsAsync`).
5. **Вибір планет у фільтрі** показує лише планети, де є флоти, і лише коли їх більше однієї.
6. **Старий тест** `ShellHeader.test.tsx` чекав, що «Флоти» неактивні. Тепер це екран, тому один рядок із переліком екранів оновлено.

## 2а. Відмінності від макета (візуал)

1. Фільтр «У польоті» показаний вимкненим із поясненням: стану польоту в даних ще немає.
2. У блоці показників немає «Швидкість (найповільніший)» і «Дрони в трюмах»: формули швидкості флоту й дронів у трюмі в даних немає.
3. Кнопка «Створити флот» вимкнена, коли немає вільних кораблів або вичерпано ліміт (у макеті порожній екран її не вимикає); причина в підказці.
4. Колір чипа класу корпусу береться по черзі з токенів за порядком класів на екрані: у даних кольору класу немає. Тому колір класу може відрізнятися від макета.
5. Панель обраного флоту липка й гортається всередині, щоб низ панелі був досяжним на невисоких екранах.
6. Мобільний екран: кнопка створення стоїть біля заголовка, а не на всю ширину під ним.
