# Задача 00067 — Сценарій бою для офлайн-гравця

> **Статус:** чернетка (чекає погодження автора)
> **Запит автора (12.11.2026):** задачі боїв з узгодженої логіки. Ця — як флот б'ється, коли гравця немає.
> **Логіка бою:** [game-design/06](../game-design/06-kosmichni-boi.md) §10.
> **Обов'язково прочитати:** `documentation/tech/08-pravyla-kodu-dlia-ahentiv.md`, `documentation/tech/09-zvedeni-pravyla-kodu-lohiky-ta-kodiv.md`.
> **Залежить від:** [00065](00065-tsykly-boiu-na-serveri.md).

## 1. Як є зараз

Після 00065 офлайн-сторона повторює попередні накази або діє за вбудованим шаблоном «стояти й стріляти».

## 2. Рішення

1. **Сценарій флоту** (06 §10) — це **типова формація флоту** (задача [00071](00071-boiovyi-poriadok-flotu.md): ескадрильї, розстановка, поведінка, розподіл трюму) **плюс правила «якщо → то»**. Розстановки й складу ескадрилей тут окремо не зберігаємо, вони беруться з бойового порядку.
2. **Правила «якщо → то»:** умова (з довідника `scenario_condition_N`: співвідношення сили, власні втрати %, номер циклу, видно носіїв/дрони, щит ескадрильї нижче %) + оператор + значення → дія (з довідника `scenario_action_N`: **застосувати формацію X у фазі розстановки** (наприклад, «якщо ворог сильніший — формація «Оборона»»), відступ усім флотом, відступ ескадрильї, змінити поведінку, змінити правило пріоритету, запустити/відкликати дрони). Правила перевіряються по черзі на початку кожної фази `orders` для офлайн-сторони; спрацьовує перше.
3. **Шаблони** (сід, адмінка): «Агресивний», «Обережний», «Зберегти флот» — готові сценарії, які гравець бере як є або копіює й змінює.
4. **Сила сторони** для умов — формула в даних (сума `damage × rate` і запасу щита/броні/корпусу видимих кораблів; коефіцієнти — налаштування).
5. **Хто вважається офлайн:** гравець не дав наказів у фазі (не натиснув «Готово» й не змінював накази). Якщо гравець з'явився — керує з наступної паузи; сценарій більше не втручається, доки він дає накази.
6. Сценарій належить флоту; новий флот отримує шаблон «Обережний».

## 3. Що зробити

1. Таблиці: `fleet_combat_scenario` (посилання на флот), `fleet_combat_scenario_rule` (ескадрильї й розстановка вже в таблицях 00071); довідники умов і дій (сід + адмінка, нейтральні коди, логічний код поведінки в програмі).
2. API: отримати, зберегти, застосувати шаблон; перевірка правил (позиції в межах зони, коди з довідників).
3. Combat: розстановка й склад ескадрилей уже застосовано з бойового порядку (00071); на початку кожної `orders` — обчислення правил і формування наказів офлайн-сторони.
4. Тести: розстановка зі сценарію, кожна умова й дія, порядок правил, гравець онлайн перебиває сценарій, шаблони застосовуються.
5. Перевірка «Перевірити»: прогін сценарію проти тестового флоту симулятором 00063 на сервері (обмеження частоти запитів), повертає підсумок.

## 4. Критерії приймання

1. Флот офлайн-гравця розставляється й діє за своїм сценарієм; шаблони доступні з коробки.
2. Усі умови й дії — дані з довідників, без чисел у коді.
3. Усі перевірки зелені.
