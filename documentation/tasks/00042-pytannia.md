# Задача 00042: рішення автора

> Задача [00042](00042-rozkladka-moduliv-po-korpusakh.md). Рішення автора 04.11.2026. Перевірки, яких агент не може зробити сам (CI, ручний перегляд у Chrome), зведено в [статус задач](../backlog/status-zadach.md), розділ «Перевірити автору».

1. **Хто затверджує розкладку:** агент готує розкладку за правилами задачі окремим документом, автор переглядає й править.
2. **Модулі бази:** ставляться на корпуси споруд, але не всі й не на всі корпуси; яка саме приналежність — в окремому документі розкладки.
3. **Дрони:** дрон не корпус, а модуль, який не встановлюється на корабель (возиться в трюмі); приналежність до корпусів для дронів не заводиться. У сіді й на сторінці виробництва група «Дрони» поки лишається серед корпусів.
4. **Форма зберігання** приналежності «модуль ↔ корпус»: обирає агент за зразком довідника Production (редагується в адмінці, новий запис доходить до гри лише даними).
