# Задача 00035: рішення автора

> Задача [00035](00035-promty-zobrazhen-obiektiv.md). Рішення автора 04.11.2026. Перевірки, яких агент не може зробити сам (CI, ручний перегляд у Chrome), зведено в [статус задач](../backlog/status-zadach.md), розділ «Перевірити автору».

1. **Стиль:** картинки об'єктів фотореалістичні, заставки сайту й фон карти мальовані; якщо разом виглядатимуть різнорідно, один набір вирівняємо.
2. **Розмір:** усі картинки 1280×720 з предметом посередині (для іконок обрізаються до квадрата).
3. **Корпуси:** 27 промптів корпусів лишаються.
4. **Раси:** будівлі й корпуси однакові на вигляд для всіх рас; расовий вигляд пізніше (наприклад, кілька полів картинки й фільтр за расою).
5. **Вигляд нових ресурсів** (Лінтрій, Орекс, Квартан, Стобій, Туманій, Силікор, Тектоніт) вигаданий агентом за назвою й лишається.
