# Задача 00057 — Питання й неперевірене

## Неперевірене (агент не може)
1. Живий прогін листа в грі: завантаження ресурсів і модулів, вивантаження, зупинка листа з причиною, швидкість з модулями в трюмі. Запущені лише збірка й міграція; тести не запускались (за вказівкою автора). Перевірити вручну в Chrome після перезапуску сервера.
2. Завантаження з планети, що не збігається з тією, де зараз стоїть флот (лист «Переліт → планета → Завантажити»): список складу береться для планети цілі перельоту, якщо вона власна; інакше показано всі ресурси без кількостей.

## Рішення за замовчуванням (змінюється одним правилом)
1. Якщо на планеті бракує потрібного для завантаження, лист зупиняється з причиною (`fleet_cargo_short`), а не завантажує наявне. У вивантаженні, як просив автор, береться наявне.
2. Завантаження й вивантаження миттєві (час 0).
3. Вага ресурсу 1 т за одиницю. Коли в даних з'являться ресурси з іншою вагою, облік трюму (зараз у тоннах = одиницях) треба перевести на тонни за вагою.
4. Вивантаження на склад планети понад його ємність: надлишок зникає за правилами складу планети (окремо не перевірялось).
5. Модулі з атрибутом «не модуль корабля» (капсули населення) у трюм не вантажаться.
