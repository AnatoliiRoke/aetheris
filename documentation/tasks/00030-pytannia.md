# Задача 00030: рішення автора

> Задача [00030](00030-zbalansovana-ekonomika.md). Числа сіду стартові, їх підбирає симулятор. Перевірки, яких агент не може зробити сам (CI, ручний перегляд у Chrome), зведено в [статус задач](../backlog/status-zadach.md), розділ «Перевірити автору».

1. **Мінерали** обов'язкові у вартості будівель з 10-го рівня, технологій з 8-го (рішення автора 04.11.2026). Окрема задача: перерахунок сіду технологій із залежностями між технологіями.
2. **Кристали на полі:** усі три, разом 3–7% маси, кожен не менше 1%, поділ випадковий (рішення автора 04.11.2026).
3. **Мінерали на планеті:** усі 4 на кожній звичайній планеті (аудит 04.11.2026).
4. **База розробки:** сід пише лише відсутні рядки, тож нові ціни й стартові будівлі потрапляють лише в нову базу (або після очищення довідників).
5. **Вирівнювання витрат ресурсів** (жоден ресурс не лежить без діла, попит відповідає пропозиції з урахуванням рідкості, Будматеріали лише для будівель) і діапазон попиту до пропозиції: баланс, підбирає симулятор.
