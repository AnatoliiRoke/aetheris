# Задача 00058 — Неперевірене

1. Живий перегляд діалогу листа для флотів із Гіпердвигуном, Джамп-двигуном, Астросканером чи Радаром і без них. Потрібен перезапуск сервера (каталог кешується).
2. Самі накази «Гіперперліт», «Стрибок» і «Сканування» ще не виконуються сервером (задача 00050, §8): наказ відкривається в діалозі, але лист із ним зупиниться з причиною «Флот ще не виконує такий наказ».
