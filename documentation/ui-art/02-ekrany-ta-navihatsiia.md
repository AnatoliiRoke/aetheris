## 2. Принципи (💡)

1. **Усе важливе за 1–2 кліки** з будь-якого екрана: ресурси, черги, флоти, бої.
2. **Адаптивність з першого дня:** макет працює на ширині від 360 px (телефон) до 1920 px. Тоді мобільний клієнт потім не доведеться малювати заново.
3. **Таймери видно завжди:** гравець бачить, що і коли закінчиться.
4. **Тривоги помітні:** атака, бій, переповнене сховище — у верхній панелі і сповіщенням.

| **Верф і конструктор** | Корпуси, слоти, модулі, енергія генератора; проєкти | Створити проєкт, будувати кораблі |
| **Флоти** | Склад флотів, командири, стан, утримання | Сформувати флот, віддати наказ |
| **Карта** | Галактика → сектор → система; туман війни | Обрати ціль, відправити флот |
| **Бій** | Окремий екран (документ 03) | Тактика між циклами |
| **Звіти** | Звіти боїв, розвідки, грабунку | Переглянути, поділитися |

| **Ринок** | Клановий / секторний / всегалактичний; обмін кредитів і торгової валюти | Купити, продати, доставка конвоєм чи порталом |
| **Клан** | Учасники, склад, дипломатія, рейтинг, війни | Керувати кланом |
| **Гільдія** | Спеціалізація гравця | Вступити, переглянути бонуси |
| **Командири** | Рівні, навички | Розподілити навички, призначити |
| **Сценарії оборони** | Правила бою для офлайну | Налаштувати шаблони |
| **Рейтинг** | Таблиці лідерів | Переглянути |
| **Адмінка** | Окремий розділ для адмінів (✅ tech/02): довідники балансу, коефіцієнт часу, гравці, скарги, журнал дій; ролі й двофакторний вхід (tech/05) | Керувати грою |

| **Магазин** | Розширення черг і флотів | Купити |
| **Довідка** | Енциклопедія гри | Читати |
| **Налаштування** | Мова, звук, анімації, сповіщення | Змінити |

## 5. Карта (💡)

- Три рівні масштабу (✅ галактика → сектор → система): колесо миші або щипок.
- На карті: свої планети, флоти (з лініями маршрутів і таймером), відомі об'єкти; поза радіусом радарів лише зірки (туман війни ✅).
- Клік по об'єкту відкриває **картку** з діями: «Атакувати», «Розвідати», «Видобувати», «Колонізувати», «Ескорт».
- 💡 Фільтри шарів: свої / клан / вороги / пірати / ресурси.

---

## 6. Основні сценарії (💡, кількість кліків)

| Сценарій | Шлях |
|---|---|
| Поставити будівлю | Планета → слот → будівля → «Будувати» (3 кліки) |
| Відправити флот у атаку | Карта → ціль → «Атакувати» → вибір флоту → «Відправити» (4 кліки) |
| Продати ресурс | Ринок → «Продати» → ресурс, кількість, ціна → «Виставити» (3–4 кліки) |
| Увійти в бій | Тривога у верхній панелі → екран бою (1 клік) |

---

## 7. Сповіщення (💡)

| Подія | Де |
|---|---|
| Атака на планету / флот | Тривога у верхній панелі + звук + (❓ браузерне сповіщення) |
| Почався бій, пауза між циклами | Тривога + таймер до наступного циклу |
| Завершено будівництво, дослідження, виробництво | Права панель, тихо |
| Флот прибув / повернувся | Права панель |
| Сховище заповнене | Значок на ресурсі |
| Кінець захисту новачка | Повідомлення за 24 год і за 1 год |
