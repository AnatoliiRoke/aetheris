# AETHERIS — Інтерфейс бою

> **Статус документа:** чернетка v0.1 (24.10.2026)
> **Позначення:** ✅ — підтверджено автором (зокрема в попередніх документах); 💡 — пропозиція; ❓ — відкрите питання.
> Пов'язані документи: [game-design/06 — Космічні бої](../game-design/06-kosmichni-boi.md), [01 — Візуальний стиль](01-vizualnyi-styl.md), [02 — Екрани](02-ekrany-ta-navihatsiia.md).

---

## 1. Що вже вирішено

- ✅ Бій тактичний, покроковий, **циклами по 5–10 хвилин**; між циклами гравець змінює тактику.
- ✅ Якщо гравець офлайн, діє **сценарій оборони**.
- ✅ Бій рахується на сервері (💡 документ 06).
- ✅ 2D, легкий стиль.
- ✅ Боєприпаси обмежені; кораблі втрачаються назавжди.

## 2. Будова екрана бою (💡)

```
┌──────────────────────────────────────────────────────────────┐
│ Цикл 2 з 6 · до наступного циклу 04:12 · [Готово]            │
├───────────────┬──────────────────────────────┬───────────────┤
│ Мій флот      │                              │ Ворог         │
│ (список груп, │     Поле бою (2D)            │ (що відомо    │

├───────────────┴──────────────────────────────┴───────────────┤
│ Накази на наступний цикл: формація · цілі · режим · дрони ·  │
│ енергія · відступ · спецдії                                  │
├──────────────────────────────────────────────────────────────┤
│ Журнал раундів (текстом) · [Переглянути анімацію]            │
└──────────────────────────────────────────────────────────────┘
```

## 3. Поле бою (💡)

- Дві сторони, у кожної **2–3 лінії** (передня, середня, задня).
- Кораблі показано **групами за типом** (наприклад, «Шершень ×24»), а не поштучно: так екран читається навіть у великих боях.
- На кожній групі: смуги **насичення щита** (✅ модель щита, game-design/14 §5.3а) і **броні/корпусу**, значок боєкомплекту, значок командира.
- Знищені групи сіріють і зникають після циклу.
- 💡 Клік по групі: детальна картка (модулі, коефіцієнти поглинання щита за типами урону, насичення, кількість ремонтних дронів, урон).

---

## 4. Накази між циклами (💡, з документа 06)

| Наказ | Елемент інтерфейсу |
|---|---|
| Формація | Перетягнути групу на іншу лінію |
| Пріоритет цілей | Випадаючий список для групи: «носії», «торпедоносці», «найслабші» тощо |
| Режим | Перемикач: атака / оборона / дистанція |
| Дрони | Кнопка «Запустити» / «Відкликати» на носії (бойові дрони). Ремонтні дрони (✅ 05a) виходять на броню після першого циклу й працюють автоматично; показується їх кількість |
| Розподіл енергії | Повзунок «щити ↔ зброя» (💡 05a) |
| Відступ | Позначити групи → «Відступити» (попередження: займе цикл) |
| Спецдії | Кнопки: РЕБ, ремонт, залп торпед |
| Готово | Підтвердити накази до кінця паузи |

💡 Якщо гравець не дав нових наказів, діють попередні. Якщо бій почався, коли гравець офлайн, діє сценарій, а з появою онлайн гравець бере керування з наступної паузи.

---

## 5. Перегляд циклу (💡)

- **Журнал**: текстові рядки по раундах («Гадюка ×12 → Кракен: 4 торпеди влучили, щит −30%»).
- **Анімація**: коротке 2D-відтворення циклу (15–30 секунд), яке можна прискорити або пропустити.
- ✅ Інтерфейс бою входить в етап 2 (production/01). 💡 Для першого випуску достатньо журналу і простої анімації (лінії пострілів, спалахи).

---

## 6. Підготовка і кінець бою (💡)

- **Підготовка**: розстановка ліній, вибір сценарію, таймер.
- **Кінець бою**: підсумок (втрати обох сторін, здобич, уламки, досвід командира, зміна рейтингу), кнопки «Звіт», «Поділитися в клані».

---

## 7. Сценарій оборони (💡)

Окремий екран (документ 02) з **конструктором правил**:

```
ЯКЩО [сила ворога] [>] [2×моя]  ТО [відвести флот]
ЯКЩО [втрати]     [>] [50%]     ТО [відступ]
ІНАКШЕ формація [оборона], цілі [торпедоносці], дрони [цикл 1]
```

- Готові шаблони: «Агресивний», «Обережний», «Зберегти флот».
- 💡 Кнопка «Перевірити» запускає симуляцію проти тестового флоту.

---

## 8. Мобільна версія (💡)

- Поле бою зверху, накази — у висувній панелі знизу.
- Групи кораблів — у вигляді списку, перетягування ліній — кнопками «вперед» / «назад».

---

## 9. Відкриті питання

1. ❓ **Групи кораблів** замість окремих кораблів на полі: так?
2. ❓ **Лінії**: 2 чи 3?
3. ❓ **Анімація** циклу чи лише журнал (для MVP)?
4. ❓ **Конструктор правил** для сценарію оборони: підходить формат «якщо → то»?
5. ❓ **Кнопка «Готово»**: якщо обидві сторони готові, цикл стартує раніше?
