# AETHERIS — client

The public site of the project (task 00003): the landing page and the account screens,
built from `documentation/design/aetheris-web 1`. How to run it, the routes and the layout
of the code are described in the root `README.md`, section «Клієнт».

```bash
npm ci
npm run dev     # http://localhost:5173, forwards /api to the server on :5080
npm run lint
npm test
npm run build
```
